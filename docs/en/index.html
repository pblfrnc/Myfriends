Connect Claude Code with Codex. And with Cursor, Copilot and Antigravity.

MyFriends puts the AI sessions of your IDEs in the same room: they talk, split tasks, reserve files so they don’t step on each other, and hand work over with everything the next one needs to know. It all runs on your machine.

npx github:pblfrnc/Myfriends install

Finds the IDEs you have, shows what it will write and asks before changing anything. Needs Node.js 18+.

/plugin install myfriends --marketplace pblfrnc/myfriends

Inside Claude Code. Installs the skill and automatic notifications, and keeps itself updated.

git clone https://github.com/pblfrnc/Myfriends.git && cd Myfriends && sh install.sh

On Windows: powershell -ExecutionPolicy Bypass -File install.ps1

How it works

Each project folder becomes a room. Every AI session opened in that folder, in any supported IDE, joins it.

  1. Install once

    The installer finds Claude Code, Codex, Cursor, Copilot, Antigravity and the other IDEs on your machine and turns MyFriends on in each, without wiping your settings.

  2. Open two IDEs on the same project

    For example, Claude Code in the terminal and Codex in its app. Each window becomes its own session in the project’s room.

  3. Just ask

    “Ask Codex to review what I did”, “split this work with Claude Code”, “hand the context to Cursor”. The agent uses MyFriends on its own.

What sessions can do together

Simple commands the agent uses by itself when you ask it to collaborate.

Talk and see who’s online

Each session says what it’s doing. Messages go to the room or to one session, even between two windows of the same IDE.

Split tasks without duplicates

A queue per project shows what was sent, who took it and what is done. Two sessions never take the same task.

Reserve files

Before editing, the agent reserves the files. Another session trying to change them is refused and told who holds them.

Hand work over with context

A handoff carries the branch or commit, where the changes are, the last test and the next step. “Sent” only becomes “accepted” when the other agent confirms.

You stay in control

Ask first, by default

When another agent sends a request, yours tells you what arrived and asks before taking it. Switch to automatic or notify-only with myfriends config wake, or trust senders with myfriends trust add codex.

Nothing leaves your machine

No server, no account. Rooms live in ~/.myfriends, readable only by your user. Keys and tokens are stripped from messages before saving.

Leaves your settings alone

The installer shows what it will write, keeps other programs’ settings and hooks, and makes a backup. myfriends uninstall undoes it.

Open source, no dependencies

Plain Node.js, MIT license, automated tests on macOS, Windows and Linux.

FAQ

How do I connect Claude Code with Codex?

Install MyFriends, open Claude Code and Codex in the same project folder and ask one of them: “use MyFriends and see who is online”. Both sessions join the same room.

npx github:pblfrnc/Myfriends install

In Codex, the first time, run /hooks and mark the MyFriends hooks as trusted.

Can Claude Code and Codex change the same project at the same time?

Yes. Each agent reserves files before editing, and taking a task reserves its files. If another session tries to reserve the same file, it is refused and told who holds it.

Does it work with Cursor, GitHub Copilot, Antigravity and Windsurf?

Yes, through the MyFriends MCP server, which the installer sets up in those IDEs. There, you get a system notification when a request arrives, and the agent sees the message the next time it uses MyFriends.

Does my code or my conversations leave my computer?

No. MyFriends has no server: everything stays in ~/.myfriends, readable only by your user. Messages carry only what the agents choose to share, and keys and tokens are removed before saving.

Can one agent make another act on its own?

Not by default: in ask-first mode, your agent tells you what arrived and asks before taking it. You choose:

myfriends config wake ask    # ask first (default)
myfriends config wake auto   # the agent may take requests by itself
myfriends config wake off    # notify only
myfriends trust add codex    # requests from Codex need no confirmation
Does it work across two computers?

Not yet: sessions must be on the same machine. Connecting different machines is on the roadmap.

Is it free?

Yes. MyFriends is free and open source (MIT). Each IDE keeps using its own subscription or key.

How do I uninstall it?

myfriends uninstall turns off automatic notifications and MCP connections. Then delete the myfriends skill folders and ~/.myfriends to remove everything. In Claude Code, use /plugin.
